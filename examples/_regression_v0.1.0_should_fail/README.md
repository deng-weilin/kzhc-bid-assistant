## 这份样本说明了什么

| 观察 | 含义 |
| --- | --- |
| R1—R8 **全部为绿** | 旧版规则完全看不出问题。R5 写"实测 `★: 1`"也判过——因为它比的是产出自己的三个字段 |
| R15 为红 | 源文本 58 处符号，产出里一处登记都没有。**27 条实质性 ★ 条款只落位了 1 条，漏拆 26 条** |
| R16 为红 | 103 条 locator 的行号体系来自另一份未随包分发的抽取文件，全部对不上 |

**结论：一份"8 项规则全绿"的产出，可以漏掉绝大部分实质性要求。校验器必须至少有一处与外部源对账。**
